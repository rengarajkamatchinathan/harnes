# Review a document

1. Find the document's purpose and audience. If they are not clear, state the assumption you made.
2. Start with the two or three most important issues: missing or wrong content, unclear argument, structure.
3. Then list specific edits as `original → suggestion`, with a short reason each. Quote the original exactly.
4. Check facts, numbers and names that can be checked from the material given; flag the rest as "please verify".
5. Note what works well, briefly, so the author keeps it.
6. Keep the author's voice. Do not rewrite the whole document unless asked.
