# wayfinder:map — Genie (multi-provider AI harness: Desktop + CLI)

> This map is an index. Decision details live in each ticket's **Resolution**.
> **Session rules:** claim ONE open, unblocked, unclaimed ticket (set `claimed-by`). Resolve it, write the
> resolution, add ONE line to *Decisions so far*, set `status: closed`, and stop. Research tickets are the exception and may batch.
> Sessions write **no production code**. Prototype code is thrown away.

## Destination
Genie is a commercial AI harness: two thin clients on one Rust core daemon.
- **Desktop (Tauri 2 + React/TS):** Chat and Code modes plus a full Settings UI. The UX follows Claude Desktop's patterns; the brand is Genie's own.
- **CLI (Rust):** a coding agent with Claude Code-level features: agent loop, tools, permissions, checkpoints, MCP, skills, hooks, subagents, headless mode.
- **Any provider:** Anthropic, OpenAI, Azure AI Foundry, Bedrock, Vertex/Gemini, and OpenAI-compatible endpoints (Ollama, vLLM, OpenRouter).
- **References:** Claude Code/Desktop for *behaviour*. OpenCode (see [knowledge/opencode](knowledge/opencode/README.md)) for *architecture*. We adapt their designs; we don't copy their code.
